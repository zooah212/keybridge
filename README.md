# 词库桥接 · KeyBridge

给**苹果自带的中文键盘**添加本地 Rime 词库，支持 **26 键全拼和九宫格**。候选查询在本地完成，不请求云端、不替换苹果词库。

**[下载测试词库](https://raw.githubusercontent.com/wm0104/keybridge/main/Tests/test.zip)** · 902 条 · [词库源文件](Tests/test.dict.yaml)

复制下面整行，粘贴到插件的 **导入与管理 → 从链接导入**：

```text
https://raw.githubusercontent.com/wm0104/keybridge/main/Tests/test.zip
```

zip 文件在仓库的 **Tests/test.zip**，导入后显示为 **test**。

> **特别注意：**Dopamine 白名单用户，安装后打开 **RootHidelnject**，检查 **kbd** 是否已注入。

iOS 15.0–16.x 兼容测试范围，不代表所有版本均已验证。

## 用法

1. 设置 → 词库桥接，在 **导入与管理** 中选择 **导入词库 zip**，也可从 https 链接导入。
2. 等待导入完成，选中词库，打开 **启用本地词库**。
3. 打开备忘录，使用苹果中文键盘输入。

主页面保留本地词库开关和词库列表，其他功能收纳为四个分类入口。点按标题原位展开，再点收起，一次只展开一组：

- **导入与管理**：导入、扫描手动放入的词库，以及直接用 Filza / Fila 打开位置、复制当前路径或词库根目录；位置操作不再套子菜单，扫描不切换当前词库。
- **词条管理**：自定义词条、排除词条、按拼音查询词库。
- **候选显示**：保留系统候选、候选数量（5 / 8 / 10 / 15 / 20），默认 5 条。
- **词库过滤**：保留繁体、保留英文、过滤生僻字（仅保留通用规范汉字表内的字）。修改后重新处理当前词库。

分类展开使用系统列表行过渡，后面的分类随内容向下移动，不弹浮层、不压暗背景；开启「减弱动态效果」时不播放展开动画。主页面与词条管理、排除词条、查询结果页统一浅灰卡片及右侧黑色功能图标（深色模式自动适配），开关保持原生控件；候选数量直接打开选择框。本地无匹配时仍保留系统候选。

词库支持点按切换、长按重命名或删除。**取消选择不影响自定义词条**；要停用全部本地候选，请关闭「启用本地词库」。

## 怎么测试

导入上方的测试词库，选中 **test**，先保留系统候选。未被过滤时共 **902 条**，其中下面三条是**故意不对应读音的测试专用编码**，方便区分系统候选与插件候选。

| 26 键输入 | 九宫格按键 | 测试候选 |
| --- | --- | --- |
| `dan` | `326` | 桥 |
| `ceshi` | `23744` | 蓝猫 |
| `bendiciku` | `236342458` | 红猫到家 |

1. **关闭「启用本地词库」**，清空后输入表中编码，确认没有对应测试候选。
2. **打开「启用本地词库」**，清空后重新输入同一编码，展开候选栏找对应测试候选。
3. **关闭时没有、开启后出现**，才是这组测试的有效对比。先不要点选上屏；若关闭时也出现，换另一组，避免系统学词或其他词库干扰。

九宫格数字指拼音键位置，不是数字键盘。请输完整编码，只输前缀也可能提前出现测试词。

没找到时，到 **词条管理 → 查询词库** 检查完整拼音。**查询有结果，不等于键盘已经显示。** 测试词库用于检查功能，不是完整日常词库。

## 适用环境

iOS 15–17，rootless 与 roothide 越狱都可以（上游真机验证到 iOS 16.3 roothide，iOS 15 rootless 仍待实机确认）。两个包由同一套脚本产出：rootless 包在 CI 上打（GitHub Actions ▸ Build KeyBridge，或 CodeMagic 的 `build-keybridge`，都只出 `-rootless.deb`），roothide 包在本机 Apelin 构建。装完在设置页导入词库，不用重启；后台状态看 `/var/mobile/Library/Keyboard/KeyBridge/install.log` 与 `KeyBridgeInjector.json`。
