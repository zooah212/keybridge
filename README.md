# 词库桥接 · KeyBridge

给 iOS 上**苹果自带的中文键盘**接一份自己的 Rime 词库：把词库候选排到苹果候选前面，26 键全拼和九宫格都支持。

苹果自带的联想和候选排序就是一坨，所以拿开源的 Rime 词库来补。

词库是**本地**的：索引就 mmap 在键盘进程里，按键直接二分查询，没有网络往返。覆盖面未必比得上云端的大模型，但输入不出本机，响应也更快。

不修改、不替换苹果的词库与学习词，只是叠加——苹果的静态词库在封存的系统卷上，格式也是私有的。

## 用法

1. 设置 ▸ 词库桥接，导入一份 Rime 词库 ZIP（选文件，或粘贴 https 链接让它自己下）。
2. 等一两分钟生成索引即可用；面板会显示条数与被过滤的繁体、英文、生僻字。
3. 可以并存多份词库，点一下切换；不需要了长按删除，键盘就回到纯苹果候选。

开关：保留繁体、保留英文、只用词库候选、过滤生僻字、候选数量（3–8）。另外可以自己加词条（优先于词库）和排除词条。
